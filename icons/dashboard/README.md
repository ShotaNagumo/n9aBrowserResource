# ダッシュボードアイコン

- `Quest.png`：任務チケット見出し用。透過背景のノートとペン。
- `Quest-black.png`：白色版を残して作成した黒色版。透過背景を維持し、明るい背景で使用する。
- `Quest-red.png` / `Quest-cyan.png` / `Quest-lightgreen.png` / `Quest-yellow.png` / `Quest-brown.png`：黒色版と同じ任務アイコンを、赤・水色・黄緑・黄色・茶色にした色違い。透過背景を維持し、任務分類別のダッシュボード表示で使用する。
- `ExpeditionFleet2.png` / `ExpeditionFleet3.png` / `ExpeditionFleet4.png`：第二〜第四艦隊の遠征用。風になびく同一の黒い旗に、番号だけを透明に抜いたアイコン。
- `ExpeditionFleet.png`：遠征旗の数字なし版。
- `ExpeditionFleetX.png`：遠征旗の「×」版。
- `Unsupplied.png`：未補給を表す、空の茶碗と空腹記号。
- `Waiting.png`：待機中を表す、お茶の入った湯呑。
- `Bath.png`：入渠を表す、正方形に近い比率の湯を張った湯船。
- 生成方法：組み込み画像生成ツール。このフォルダを正本として起動時に取得する。APKへ別コピーを同梱しない。
- 生成指示：司令部要員に描かれたノートとペンをイメージし、小さな見出しでも識別できる形にする。情報エリアと同様の白に近い単一色（#E6EDF5）を使用し、ノートとペンの境目や細部は透明な抜きで表現する。マテリアルデザイン風、文字・周囲のバッジ・陰影・グラデーションなし。背景は透過。組み込み画像生成ツールで初版を修正。

- `UnitBadge_1_White.png`等の`UnitBadge_艦隊番号_色.png`：盾の中に艦隊番号を表示する艦隊ステータスチケット用アイコン（第一～第四、白・オレンジ・赤）。
- 出典と基本ライセンスは [出典一覧](../../THIRD_PARTY_NOTICES.md) を参照。

## 解析停止通知

FleetUpdateStopped.png は歯車と警告三角形を組み合わせた黄色 #FFEB3B の透過PNG。ダッシュボード先頭の解析停止通知に使用する。最新の黄色候補を採用し、黒い艦船・更新矢印版を置き換えた。
