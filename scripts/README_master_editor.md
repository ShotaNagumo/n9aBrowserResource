# 手動マスター編集GUI（Windows・localhost）

Python 3.10以上、標準ライブラリのみで動きます。Wiki更新ツールとは別に、手入力で追加・編集するための画面です。

## 起動

`scripts/start_master_editor.cmd` をダブルクリックしてください。ブラウザが自動で開きます。PowerShellから起動する場合はリポジトリのルートで次を実行します。

```powershell
py -3 scripts/master_editor.py
```

`py` がない環境では `python` に置き換えてください。空いているポートを自動選択し、画面のURLを起動ウィンドウに表示します。固定したい場合は `--port 8877`、ブラウザの自動起動が不要なら `--no-browser` を指定できます。終了は起動ウィンドウでCtrl+Cです。外部のPCからはアクセスできません。ネット接続・追加パッケージは不要です。

## 基本操作

1. 上部の「任務」「味方艦」「敵艦」を選びます。
2. 新しく登録する場合は「新規追加」、既存データを変える場合は検索して一覧から選びます。
3. ゲーム内部IDと項目を入力します。Wiki任務番号や図鑑No.とは異なります。
4. 「変更を確認」で保存先と差分を確認します。
5. 問題なければ「この内容で保存」を押します。

入力しただけではマスターは変わりません。登録済みIDの新規追加、編集中のID変更、確認後の他ツールによる更新、型・値の範囲・未知の条件をチェックします。未保存のまま画面を切り替えると確認します。データ自体の削除ボタンはありません。

保存後は通常どおりGit差分とアプリ側の回帰テストを確認し、公開手順へ進んでください。GUIはコミット・Release公開・manifest更新を自動実行しません。旧インポーターをそのまま再実行すると手動編集を上書きし得るため避けてください。

## 任務

既存の `quest-catalog.json` と `recurring-quests.json` を同時に扱います。

- 基本情報：内部ID、任務名、説明、補足、周期（日・週・月・単発・四半期等・年次開始月）、対象艦隊。
- 達成条件：条件行を追加／削除し、必要回数、海域、マス、勝利評価、遠征ID、装備の指定方法などを入力します。
- 観測イベント形式：撃沈、遠征成功、補給、入渠、開発、建造、解体、改修、近代化改修等。対象ID・資材ID・追加閾値はイベントの仕様に合わせて指定します。
- カウンタなし：説明・編成条件だけを登録する任務用です。独自の進捗加算はせず、ゲームから来る達成状態を使います。
- 編成条件：「すべて」「いずれか」、隻数、指定候補を組み合わせます。艦種・艦型・国籍・艦識別・レベル・指定艦の改装形態、旗艦等の位置を指定できます。

複数の達成条件はすべて満たす必要があります。海域などのマス指定は表示記号ではなく内部IDです。対象艦隊のチェックをすべて外すと艦隊を限定しません。nativeの観測イベントと編成・艦隊条件の併用は、現在評価されるbattle／practiceだけを許可します。既存の条件に未対応部分がある場合は、省いて保存せず、アプリ実装と照合してください。

「詳細JSON・互換情報」では編集対象の構造を確認し、フォームで扱いにくい条件をJSONで入力できます。「フォームのJSONを表示」で現状を取得し、編集後は必ず「JSONをフォームに反映」を押します。JSONはコードとして実行しません。`legacyCounterKeys`／`legacyDefinitionHash` は読み込み時の値を保護し、変更すると保存を拒否します。

## 艦データ

味方艦は `ship-growth.json` の回避・対潜の初期下限・初期上限・Lv99値を編集します。確定した初期値は上下限を同じにします。「値が未確定」は既存形式の `[0,9999,9999]` に対応します。敵艦分の成長行が同じファイルにあっても、味方一覧には表示せず保持します。

敵艦は `enemy-ship-hp.json` の初期耐久と `enemy-aircraft-slots.json` の5スロット分の個別搭載数を編集します。総搭載数から分配しないでください。新規で片方だけ分かる場合はもう一方を未設定にできます。既存の値を空欄にして消去する操作は拒否します。

艦名メモはGUIの一覧表示用で、手動変更の記録へ保存します。**艦名・艦種・改装先等のゲーム基本マスターを置き換える機能ではありません。** これらは従来どおりアプリがゲーム応答から取得します。

## 保存と復旧

データは既存の5つの配信JSONへ保存し、根拠メモ・艦名メモは `definitions/master-update-provenance.json` に手動入力として記録します。端末固有のファイルパスは公開データへ保存できません。

直前の保存前バックアップと中断記録はGit対象外の `local/manual-editor/` に保存します。保存中の例外では元へ戻し、強制終了等で中断した場合は画面上部の「中断した保存を復旧」から戻せます。復旧対象に別の編集があれば自動上書きしません。バックアップは次の保存で更新するため、完了済みの古い操作の取り消しはGitの差分・履歴を用いてください。

Wiki更新ツールとは同じ書き込みロックを使います。互いの更新後は一覧を再読み込みしてください。中断状態のまま別ツールで編集せず、先に元のツールで復旧します。

## 検証

```powershell
py -3 -m unittest discover -s scripts/tests -v
py -3 scripts/check_public_paths.py
```

127.0.0.1だけで待ち受け、リクエスト先Host・Originと起動ごとのトークンを確認します。公開サーバーとしての運用は対象外です。画面資産と5種類のマスター／出典記録だけを扱い、任意ファイル読み書き用のAPIはありません。
